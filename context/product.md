# Product Context

This file is the shared source of truth for what is being grown. Replace the example with the active product before connecting external action adapters.

## Example product

An AI-native Minecraft English speaking course for children. Learners progress through in-game tasks by speaking English with an AI teacher and teammates.

## Product value event

A session is not successful merely because a child launched the game. The product should emit verified learning / task events such as valid speech turns and lesson completion.

## Growth implication

Optimize acquisition for downstream successful learning and paid retention, not clicks, installs, or raw registrations.
