# Positioning

## Core promise

Turn game motivation into repeated, contextual English speaking practice.

## Product language

Prefer observable outcomes:

- verified speaking turns;
- completed collaborative tasks;
- lesson completion;
- repeat successful sessions.

Avoid leading with implementation jargon such as “multi-agent”, “realtime pipeline”, or “LLM orchestration” unless the audience is technical.

## Messaging hypothesis examples

- “A Minecraft world where speaking English moves the game forward.”
- show a real lesson moment before explaining the underlying AI;
- show the parent an after-class learning report with concrete evidence.
