# ICP Context

## Buyer

Parent or guardian evaluating an English learning product for a child.

## User

Child learner using the game-based lesson experience.

## Core problem

Traditional practice often fails to create enough voluntary, contextual English speaking repetitions.

## Existing behavior

The learner is already motivated by Minecraft or game-based exploration.

## Qualification signals

- parent wants speaking practice rather than only test preparation;
- learner is comfortable with Minecraft-style controls;
- household can support the required lesson setup;
- learner can participate in the target age / course range.

## Disqualification / caution

Do not treat minors as outbound sales targets. Consumer contact and purchase decisions should route through the responsible adult and comply with applicable platform and privacy rules.
