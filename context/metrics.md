# Metrics

## North-star candidate

**Weekly Successful Learning Sessions**

A successful session should be defined by product evidence, for example:

```text
lesson_completed = true
AND valid_speech_turns >= configured threshold
AND critical_error = false
```

The exact threshold belongs in product configuration, not in marketing copy.

## Funnel metrics

- lead → trial booking
- booking → attendance
- attendance → first verified value
- activation → lesson completion
- completion → report viewed
- report viewed → paid
- paid → repeat successful session

## Guardrails

- refund / complaint rate
- support burden
- lesson critical-error rate
- acquisition cost
- inappropriate or unauthorized outbound actions

Vanity metrics such as impressions and clicks are diagnostic inputs, not final optimization targets.
